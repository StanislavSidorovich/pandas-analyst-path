Pandas Analyst Path

One Colab notebook that takes you from the first df.head() to real business questions: KPIs, cohorts, RFM, churn, funnel. 137 small tasks, each auto-checked, and the checker explains why an answer is wrong.

Open in Colab Cheat sheet

How to start

  1. Open in Colab, then File → Save a copy in Drive. From now on work in your copy, on a laptop, tablet or phone.
  2. Run the ⚙️ Setup cell, then the ▶ Part setup cell of the part you are on.
  3. Solve a task and run its check("1.1") cell.

No Google login is needed for the data: a snapshot of the dataset downloads automatically.

When you are stuck

Add a cell under the task (+ Code) and climb the ladder:

  1. cheat(): the concept table for this task
  2. hint(): a nudge; run it again for a stronger one
  3. compare(): your answer next to the expected one
  4. solution(): one possible solution, to retype yourself
