Task 1.10 · The biggest category

Which product category has the most products? Store its name (a string).

top_category = products['category'].value_counts().max()
check('1.10')
✗ Task 1.10: not yet. Expected text (a string), but you have int64. Typical mistake: `.max()` gives the biggest count. You need the label: `.idxmax()`.
top_category = products['category'].value_counts().idxmax()
check('1.10')
